# v2.1.7 — 加快打开面板、保存跟进和完成任务

本地维护版，适用于 Logseq 2.0.2 起的 2.x 数据库图谱。

- 已迁移的图谱启动时，首轮查询同时用于检查迁移情况和填充面板。如果本次迁移写入了提醒，插件会再读取一次结果。
- 面板在展开时创建跟进表单和操作历史，倒计时显示的文字发生变化时才更新。点开任务标题可直接查看原任务块。
- 保存跟进和完成任务时，插件用已有的提醒记录准备操作，一次查询核对当前记录、任务状态与原始标题，写入后再回读验证。如果正文的「完成」按钮遇到同步冲突，插件会取回这项任务供下次操作使用。

替换插件后，在插件页重载 Async Task Timer 即可使用。
