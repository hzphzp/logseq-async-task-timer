# v2.1.5 — 点击响应与保存性能优化

本地维护版，继续仅支持 **Logseq >= 2.0.2, < 3.0.0 的数据库图谱**。不恢复旧版或文件图谱支持；无数据迁移。

- 正文「跟进」立即显示设置窗口，只读取目标任务，不等待全量提醒扫描。读取期间显示进度、禁用保存，并保留用户正在输入的内容。
- 工具栏先显示已有列表，再后台刷新；关闭窗口、重新打开另一任务或切换图谱时，旧读取不会重新打开或覆盖新窗口。
- 完成任务和保存跟进时间，在写入并核验成功后直接更新对应记录；无需在动作前后扫描整个列表。晚到的旧扫描会重新读取，不能覆盖新保存结果。
- 保存关键路径保留权威读取、冲突检查和保存校验，省去重复的显示标题解析。八项属性定义合并成一次查询；原生状态 ID 仅在当前图谱的 store 内缓存。
- 保存时提供即时进度与按钮状态，内联完成操作防止双击重复写入。保存期间仍可查看分组、展开跟进表单或关闭窗口。
- 保留首次完成任务与撤销修复，以及保存超时后的自动重连和不重发写入规则。

验证覆盖：真实 Logseq 2.0.2 worker 的独立、未同步测试图谱；首次完成与撤销、完整提醒生命周期、迁移、原正文/子块保全、跨设备冲突、丢失写入响应；另有慢读取、保存与后台扫描交错、双击、关闭/重开、切图和未保存表单的回归测试。正式笔记没有用于写入性能测试。

交互改进不代表数据库写入没有耗时。只有数据库回读确认后，界面才将操作显示为成功。
