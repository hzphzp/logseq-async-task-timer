# v2.1.8 — 已有提醒可直接跟进，保存时可继续操作其他任务

适用于 Logseq 2.0.2 起的 2.x 数据库图谱。已有提醒和操作历史无需迁移。

- 从正文「跟进」或斜杠命令打开已有提醒时，可直接输入分钟数或选择预设。第一次为某个块设置提醒时，插件从任务查询中同时取得块标题，无需额外加载子块。
- 点面板中的「完成」或保存跟进后，可以继续处理其他任务。当前任务显示保存进度，同一项不能重复提交。多项修改按顺序写入，核对数据库后才显示成功。
- 同一个块同时出现在正文和引用区域时，各处的「完成」按钮都显示当前保存状态。遇到其他设备的修改时，插件取回新值，保留已输入的草稿供核对，不会自动重试写入。
- 保存仅提交有变化的提醒字段和本次历史。短时间内重开工具栏面板可复用刚核对过的列表。后台刷新从同一份数据中取回新版提醒和仍待迁移的旧记录；已迁移的旧值不再重复读取到插件。

本地替换插件文件后，在插件页重新启用 Async Task Timer 即可生效。
