# v2.1.6 — 点击任务标题直接定位块

本地维护版，继续仅支持 **Logseq >= 2.0.2, < 3.0.0 的数据库图谱**。

- 面板中的任务标题直接打开原任务块及其子块，通过原生面包屑返回所在日志或页面。
- 移除对 `scrollToBlockInPage` 的依赖：此前打开整篇日志后再尝试滚动高亮，现在直接进入任务块视图，不依赖所在页面的展开和滚动状态。
- 工具栏时钟使用有可访问名称的原生按钮，支持键盘和辅助工具操作。
- 跳转只读取目标块，不查询所属页面、不扫描全部提醒、不修改正文、任务状态或跟进时间。
- 目标已删除或路由失败时保留面板并显示错误；关闭面板、切换图谱或打开新窗口后，不执行过期的跳转，也不让旧响应关闭新窗口。

保留 v2.1.5 的交互性能优化、保存校验和超时恢复。本次无数据迁移，更新插件后重载生效。
