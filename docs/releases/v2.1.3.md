# v2.1.3 — Logseq 插件通信超时恢复

本地修复版；兼容范围保持 **Logseq >= 2.0.2, < 3.0.0 的 DB 图谱**，不支持旧版文件图谱。

- 识别 `[deferred timeout] async call #…`，使用逐步延长的间隔自动重连，连续失败只保留一个重连任务。
- 后台读取失败时保留已有列表、输入和展开状态；恢复后重新核对数据库，不重新迁移已初始化的图谱。
- 保存或保存校验超时时不自动重发写入；排队中的后续修改暂停，读取确认后恢复操作。
- 批量导入和同步触发的刷新合并处理，最多每 5 秒启动一次；到期与手动刷新继续按需执行。
- 图谱切换或插件卸载会取消旧图谱的恢复流程；旧调用晚到的超时不会影响新图谱。
- 断线期间新到期的提醒只汇总，不补发企业微信；真正的查询、属性或数据错误仍然显示。

验证：自动化测试涵盖启动与后台超时、缓存保留、重连退避、写入不重放、图谱切换和原有提醒行为。真实 2.0.2 worker 测试模拟“写入成功但响应超时”，确认只写入一次并完整保留历史。测试使用隔离图谱和模拟企业微信传输，没有向真实群发送测试消息。
