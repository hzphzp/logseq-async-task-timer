# v2.1.10 — 到期提醒、任务排序与正文显示

本版本适用于 **Logseq 2.0.2 起的 2.x 数据库图谱**，已在桌面版 2.0.2 验证。文件图谱请继续使用 v1.6.7。

自上一个公开版本 v2.1.2 以来：

- 「已到期」把刚到期的任务排在最前面。面板打开时，新到期的任务会自动移到顶部。
- Logseq 运行期间，插件单独等待最近的截止时间。切回前台、从休眠唤醒或恢复数据库连接时，迟到十分钟以内的有效提醒会补发一次。系统通知需要授权，企业微信推送由配置的设备发送。
- 点击任务标题可直接打开原任务块及其子块。跟进已有任务时可立即输入时间，保存期间也可继续操作其他任务。
- 修复数据库调用超时后的恢复，以及首次完成任务时可能出现的保存校验错误。保存时核对原任务状态与历史，避免重复记录。
- 在新图谱中创建属性时，默认从正文隐藏 `reminder-state`、`next-follow-up` 和 `last-checked`。已有属性沿用图谱中的显示设置，三个字段都可查询。

下载 `logseq-async-task-timer-v2.1.10.zip`，解压到 Logseq 插件目录后重载插件。从 v2.1.2 升级可继续使用已有提醒及历史。
