# v2.1.4 — 首次完成任务的保存校验修复

本地修复版，继续支持 **Logseq >= 2.0.2, < 3.0.0 的 DB 图谱**。

- 修复原生任务尚无插件提醒记录时直接点击“完成任务”的错误。旧逻辑只在已有提醒记录时更新原生状态，会写入完成历史却把任务留在 Doing，随后触发 `Save verification failed`。
- 现在首条完成记录与所请求的原生 Done 状态一起保存；撤销仍可恢复原先的 Doing 状态。
- 保存和撤销校验采用规范化字段比较，避免仅因对象键顺序不同而误判。
- 保留 2.1.3 的超时重连、列表保留及不重复写入机制。

验证：先用回归测试复现旧版保存校验失败，修复后全部 36 项自动化测试通过。真实 Logseq 2.0.2 worker 的独立图谱测试覆盖“无提醒历史的 Doing 任务 → 完成 → 撤销”，以及原有迁移、提醒生命周期、历史保留、冲突检查和丢失保存响应的场景。

本次对已报错任务的原生状态补齐是单独修复，不属于插件自动批量改写行为。
